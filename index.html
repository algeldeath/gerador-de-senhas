Qual é a diferença?

🔑 Senha normal

É uma sequência de caracteres que você pode usar para entrar em uma conta. O gerador cria uma sequência aleatória; ele não a criptografa automaticamente.

🔐 Hash criptográfico

Transforma o texto em uma sequência de tamanho fixo. O processo é projetado para não permitir recuperar diretamente o texto original.

🔒 Criptografia verdadeira

Usa uma chave para transformar os dados e, quando o algoritmo e a chave permitem, recuperar o conteúdo original por meio da descriptografia.
